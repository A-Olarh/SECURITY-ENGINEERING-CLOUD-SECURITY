SCENERIO

PayFlow is a fictional digital banking/fintech platform that allows individuals and small businesses to manage money, make payments, and transfer funds over its web and mobile applications.

APPLICATION INFORMATION

*1. Users*

The platform has three categories of users:

*Customers*

*Support Staff*
• Help customers with account issues

*Administrators*
• Manage application infrastructure and configuration

The PayFlow application provides:

• User registration and authentication
• MFA
• Account/balance management
• Money transfers

• Admin/support portal
